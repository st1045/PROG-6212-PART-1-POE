# PROG-6212-PART-1-POE

**Main purpose of the project
The RaceDay application intends to develop a web-based system for facilitating the management of cycling, walking, and running competitions. Where athletes are able to search for competitions, register for those competitions, and record their competition history, organizers can create and manage competitions, competition categories, athlete registrations, and results.
**Functionality of the application
Running, walking, and cycling competitions can be administered via the RaceDay application. Competitions, categories, registrations, and competition outcomes can all be made and administered by administrators. Besides registration and signing into the system, competitors will be able to check their participation records, enroll in competitions, view the list of available competitions, and access their results. To ensure that Administrators and Competitors have access to the features pertinent to their roles, the application also uses role-based access control.
